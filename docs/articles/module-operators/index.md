# Operators

The Operators module provides management capabilities for operators and their skills, including attendance tracking and skill assignments.

## Provided Facades

- [`IOperatorManagement`](/src/Moryx.Operators/IOperatorManagement.cs) - for operator management
- [`ISkillManagement`](/src/Moryx.Operators/Skills/ISkillManagement.cs) - for skill management
- [`IAttendanceManagement`](/src/Moryx.Operators/Attendances/IAttendanceManagement.cs) - for attendance tracking

## Provided Endpoint

This module provides a REST API for managing operators and skills. See [Operators Endpoint](endpoint.md) for details on available operations and permissions.
