# Web

## Supported Screen Sizes

All MORYX web UIs are designed for desktop-like environments such as manufacturing HMIs, industrial panels and standard desktop browsers.

### Minimum Resolution

The minimum supported screen resolution is 1280x720 px (HD). The recommended resolution for comfortable use is 1920x1080 px (Full HD).

All module UIs use tree-detail or list-detail layouts that require sufficient horizontal space to display both panels side by side. Below 1280px, some UIs switch to overlay navigation or collapse form layouts, but the overall experience is not optimized for narrow screens.

### Mobile Devices

Mobile phones are not supported. The web UIs do not include responsive layouts for small screens and will not provide a usable experience on these devices.

Tablets with a viewport width of 1280px or more (e.g. landscape iPad) should work without issues. Smaller tablets in portrait mode may experience layout issues due to insufficient horizontal space.
