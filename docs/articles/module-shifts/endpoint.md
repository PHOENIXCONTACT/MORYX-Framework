# Shifts Endpoint

The Shifts Endpoint provides a REST API for managing shifts, shift types, and shift assignments to operators and resources.

## Facade

This endpoint is based on the [`IShiftManagement`](/src/Moryx.Shifts/IShiftManagement.cs) facade for shifts, shift types, and shift assignments.

## Controllers

- **ShiftManagementController**: Manages shifts, shift types, and shift assignments

## Permissions

No permissions are currently defined for this endpoint.
