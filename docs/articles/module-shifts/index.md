# Shifts

The Shifts module provides management capabilities for shifts, shift types, and shift assignments to operators and resources.

## Provided Facade

- [`IShiftManagement`](/src/Moryx.Shifts/IShiftManagement.cs) - for shift management operations

## Provided Endpoint

This module provides a REST API for managing shifts. See [Shifts Endpoint](endpoint.md) for details on available operations and permissions.
