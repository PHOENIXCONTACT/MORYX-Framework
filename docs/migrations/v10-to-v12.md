# MORYX 10 to 12

## MORYX-Launcher

- Internalized components. Use `AddMoryxLauncher` extensions to register the components in the DI container.
- Created new `Moryx.Web` project for base web UI functionality.
- Renamed `LauncherRegionAttribute` to `ViewRegionAttribute`.
- Moved `ViewRegionAttribute` to `Moryx.Web`.
- The `Moryx.Launcher` layout has now a new `Top` region between the MORYX image and the search field at the top, where custom views can be placed.
- Default theme changed from `light` to `system`.

## MORYX

### Entry

- `Entry.ValuesEqual` is now order-sensitive. Sub-entries are only equal when they are in the same order.
  - Removed the overload `Entry.ValuesEqual(Entry, Entry, bool orderSensitive)`.
- `ArrayIListStrategy` is now `internal`. It is used internally by `EntryConvert` and should not be instantiated directly.

### Workplan Validation

- Changed `ValidationResult.Errors` from `ValidationError[]` to `IReadOnlyList<ValidationError>`.
  - `result.Errors.Length` -> `result.Errors.Count`

## MORYX-Container

- `CastleContainer` now requires an `IServiceProvider`. Removed the parameterless constructor and `CastleContainer(IDictionary<Type, string>)`.
  - `new CastleContainer()` -> `new CastleContainer(serviceProvider)`
  - `new CastleContainer(strategies)` -> `new CastleContainer(strategies, serviceProvider)`
- The optional `serviceProviderTypeFilter` parameter was replaced by explicit overloads with and without the filter. Passing `null` for the `IServiceProvider` or the type filter now throws an `ArgumentNullException`.
  - `new CastleContainer(strategies, serviceProvider, null)` -> `new CastleContainer(strategies, serviceProvider)`
  - Use `new CastleContainer(serviceProvider, typeFilter)` to bridge filtered types without strategies

## MORYX-Runtime

- `ModuleContainerFactory` now requires an `IServiceProvider`. Removed the parameterless constructor.
  - `new ModuleContainerFactory()` -> `new ModuleContainerFactory(serviceProvider)`

## MORYX-AbstrationLayer

### ResourceRegistrationAttribute

- Removed singleton constructors `ResourceRegistrationAttribute(Type)` and `ResourceRegistrationAttribute(Type, params Type[])`. Resources are managed by the ResourceGraph and should not be registered as singletons. For usage of plugins in this module, refer to general [dependency-injection](/docs/articles/framework/dependency-injection.md).

### ResourceInitializerBase

- Removed obsolete `InitializedAsync` overloads
- Merged `IReferenceCollectionExtended` into `IReferenceCollection`

### IResourceTypeTree

- Merged `IResourceTypeTreeExtended` into `IResourceTypeTree`
  - `IResourceTypeTreeExtended.GetNode(IResource)` -> `IResourceTypeTree.GetNode(IResource)`
- Removed obsolete `ResourceExtensions.ResourceType(this IResource)`. Use `IResourceTypeTree.GetNode(resource).ResourceType` instead.

### WorkplanExtensions

- `Validate(this IWorkplan)` now throws a `WorkplanValidationException` instead of a `System.ComponentModel.DataAnnotations.ValidationException`.
  - The errors are provided in `WorkplanValidationException.Errors` instead of a concatenated message. Use `ValidationError.Print(workplan)` to get a readable message per error.

### Resources Endpoints

- Renamed `ResourceModificationController` to `ResourceManagementController`.
- Renamed permission value `ResourcePermissions.CanViewTypeTree` from `"CanAddResource"` to `"CanViewTypeTree"`.

## MORYX Operators

- Renamed `AttendanceChangedArgs` -> `AttandanceData`
- Merged `IAttendanceManagementExtended` into `IAttendanceManagement`
  - `IAttendanceManagementExtended.GetAttendingOperators` -> `IAttendanceManagement.GetAttendanceData`

## MORYX-ControlSystem

- Removed obsolete `ModifyProductInstance<TInstance>(Action<TInstance>)` and `TryModifyProductInstance<TInstance>(Action<TInstance>)` extensions on `IProcess` and `Session`. Use `GetProductInstance<TInstance>()` and assign the properties directly.

## MORYX Process Engine

- Merged `IProcessControlExtended` into `IProcessControl`
  - `IProcessControlExtended.LoadArchivedProcessAsync` -> `IProcessControl.LoadArchivedProcessAsync`

## MORYX-Drivers MQTT

- Removed obsolete `JsonFormat.PascalCase` enum member. Use `JsonFormat.Default` instead.

## MORYX Shifts

- Changed `BaseRef` from `ShiftManagement` to `Shifts`. Update any routing or configuration that references the old path.

## MORYX Media

- Removed `ImagePreviewCreator`. It was already non-functional and only logged a warning. Use the `FFmpegPreviewCreator` instead.
  - Remove any `ImagePreviewCreatorConfig` entries from `PreviewCreators` in `Moryx.Media.Server.ModuleConfig.json` and replace them with a `FFmpegPreviewCreatorConfig` entry if necessary.

## MORYX ProcessData SpreadsheetsListener

- Upgraded `CsvHelper` to v34. See the [CsvHelper migration guide](https://github.com/JoshClose/CsvHelper/blob/master/docs/releases/v34.0.0/migration.md) if you use `CsvHelper` directly.
- Renamed `SpreadsheetsListenerConfig.Delimiter` to `SpreadsheetsListenerConfig.Separator`. Rename the `Delimiter` entry of the listener configuration to `Separator`, otherwise the default `;` is used.
  ```json
  "Separator": ";"
  ```
- Only single character separators are supported. Longer values are truncated to their first character.
- Timestamps are written in ISO 8601 round-trip format (e.g. `2026-11-23T07:14:07.3649880Z`) instead of `MM/dd/yyyy HH:mm:ss`.
- The timestamp in the file name (`<Measurand>_yyyyMMdd_HHmmssfff.csv`) is now in UTC instead of local time.

## MORYX-Notifications

- Removed old notifications bar from `Moryx.Launcher`.
- Added new notifications bar to `Moryx.Notifications.Web`.
- The new notifications bar must be configured in `Moryx.Launcher.LauncherConfig.json` to appear in the new `Top` region.
  ```json
  "Regions": [
    {
      "Region": "Top",
      "Name": "NotificationsBar"
    }
  ],
  ```
