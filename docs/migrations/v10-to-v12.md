# MORYX 10 to 12

## MORYX-Launcher

- Internalized components. Use `AddMoryxLauncher` extensions to register the components in the DI container.
- Created new `Moryx.Web` assembly for base web UI functionality.
- Renamed `LauncherRegionAttribute` to `ViewRegionAttribute`.
- Moved `ViewRegionAttribute` to `Moryx.Web`.
- The `Moryx.Launcher` layout has now a new `Top` region between the Moryx image and the search field at the top, where custom views can be placed.

## MORYX-AbstrationLayer

### ResourceInitializerBase

- Removed obsolete `InitializedAsync` overloads
- Merged `IReferenceCollectionExtended` into `IReferenceCollection`

## MORYX Operators

- Renamed `AttendanceChangedArgs` -> `AttandanceData`
- Merged `IAttendanceManagementExtended` into `IAttendanceManagement`
  - `IAttendanceManagementExtended.GetAttendingOperators` -> `IAttendanceManagement.GetAttendanceData`

## MORYX Process Engine

- Merged `IProcessControlExtended` into `IProcessControl`
  - `IProcessControlExtended.LoadArchivedProcessAsync` -> `IProcessControl.LoadArchivedProcessAsync`

## Moryx Notifications

- Removed old notifications bar from `Moryx.Launcher`.
- Added new notifications bar to `Moryx.Notifications.Web`.
- The new notifications bar must be configured in `Moryx.Launcher.LauncherConfig.json` to appear in the new `Top` region.
  ```json
  "Regions": [
    {
      "Region": "Top",
      "Name": "NotificationsBar"
    }
  ],
  ```
