Level up your factory

MORYX is an open-source .NET framework for manufacturing execution and shop-floor control. It provides digital twins of resources and products, process control, worker guidance and machine integration via OPC UA and MQTT, so you can build the applications that run your production.

MORYX runs assembly and production lines of industrial manufacturers. Most of these applications are proprietary products of the companies that build them, so they are not publicly visible.

What you can build

Modular manufacturing systems

Add or remove production cells and stations at any time. New capabilities are used immediately, without changing existing workplans.

One-piece flow and mass production

The process engine dispatches jobs and routes every article through the cells that can process its next step.

Worker assistance

Visual instructions guide workers through manual steps, let them confirm execution, report problems and record inputs.

Machine integration

Drivers for OPC UA, MQTT, TCP and serial connections encapsulate the devices behind typed digital twins of your resources.

Enterprise integration

Connect PDM and ERP systems to enrich their data and feed orders and products into production without duplicating them.

Ready-made web UIs

Modules for products, resources, orders, shifts, operators and more come with REST APIs and web interfaces.

Get started

Create an application

Install the MORYX CLI, a dotnet tool, and generate your first application in minutes. The CLI requires the .NET 8 runtime, applications target .NET 10. 

dotnet tool install -g Moryx.Cli
moryx new Factory

Want to see a complete application first? The MORYX Demo simulates the production of electronic goods in a four-step process.

Built on .NET

MORYX plugs into ASP.NET Core. Register the MORYX services, then run the modules alongside your web application. 

builder.Services.AddMoryxKernel();
builder.Services.AddMoryxModels();
builder.Services.AddMoryxModules();

var app = builder.Build();
app.Services
  .UseMoryxConfigurations("Config");

var modules = app.Services
  .GetRequiredService<IModuleManager>();
await modules.StartModulesAsync();
await app.RunAsync();
await modules.StopModulesAsync();

Security and maintenance

Maintained by Phoenix Contact

MORYX is developed and maintained by Phoenix Contact. Long-term support releases follow the .NET release schedule.

Coordinated disclosure

Report vulnerabilities privately through GitHub or the Phoenix Contact PSIRT. We fix them and publish security advisories in coordination with the reporter.

Transparent supply chain

Every release ships a software bill of materials (SBOM). Our security policy lists the supported versions and our reporting duties under the EU Cyber Resilience Act.
